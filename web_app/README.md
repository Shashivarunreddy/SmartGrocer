# SmartGrocer Web App

Next.js frontend application replicating the SmartGrocer mobile application with full mobile-responsive design, TypeScript, Tailwind CSS, and Clerk Authentication.

## Features

- **🏠 Home / Dashboard:** Live weekly budget tracker with visual adherence bar, Python AI replenishment recommendations with one-tap add, expiring soon pantry alerts, and quick category jumps.
- **🔍 Catalogue:** Search 1,000+ UK supermarket items across categories (Fresh Produce, Dairy & Eggs, Bakery, Meat, Beverages, Snacks, Pantry Staples) with live filtering and instant "+ Add to List" feedback.
- **🛒 Shopping Lists:** Active list management, real-time bill estimator, checkbox marking, quantity adjustments, "Swap & Save" cheaper alternative suggestions, and "Complete Shopping Run" modal that syncs to pantry inventory and records spending.
- **🥫 Pantry Inventory:** Freshness tracking with shelf-life countdown badges (Critical, Expiring Soon, Fresh), "Add Pantry Item" modal, and "Log Consumption" modal (Consumed vs Wasted with waste reason metrics).
- **🍳 Chef AI & Insights:**
  - **Chef Recipes:** Zero-waste meals generated by Gemini AI / pantry heuristics prioritizing expiring items. Clicking **"Add Missing Ingredients"** immediately adds missing groceries to your active shopping list and removes the section from the recipe card!
  - **AI Assistant:** Interactive grocery chatbot powered by Gemini 1.5 Flash and Python forecasting.
  - **Smart Insights:** Demand forecasting radar and food waste risk analyzer.
- **👤 Profile & Settings:** Household size configuration, default weekly budget editor, dietary restrictions/allergies tags, and lifetime spending/waste prevention analytics.
- **🤖 Floating AI Assistant:** Bottom-right floating action button present on all screens to ask Chef Gemini questions anytime.
- **🔐 Clerk Authentication:** Replicates mobile authentication with quick 1-click test user logins (`user1@gmail.com` to `user10@gmail.com`, password `GrocerPass@1` to `GrocerPass@10`).
